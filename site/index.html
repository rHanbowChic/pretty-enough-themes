能做什么

下面每个按钮都会在上方的演示里操作一次。

  • 立即切换

    在站点默认、无版式、内置版式和自定义版式之间切换，已打开的页面随即更新，不用刷新。

  • 全部站点，或只改这一个

    版式可以对所有站点生效，也可以在弹出菜单里单独设置某个站点。使用自己域名的站点也一样。

  • 自定义版式

    从网址或本地 CSS 文件添加版式。任何内置或自定义版式都可以克隆，副本能在设置页直接编辑。

  • 收藏站点的版式

    看到好看的站点，用弹出菜单的加号把它的版式存进自定义版式，多个样式表也会全部保留，之后可以用在别的站点上。

  • 附加 CSS

    每个版式都能追加一段自己的 CSS，比如设置社区版式的 CSS 变量。写在「站点默认」上同样有效。

  • 顶栏不错位

    不少站点把菜单包在 .top-bar 和 .mobile-top-bar 里，老版式不认识它们，于是出现两个顶栏。扩展会在需要时还原 wikidot 的原生结构，也可以按版式手动指定。

主题色从 CSS 里算出来

弹出菜单用三个色块展示版式。它们只根据 CSS 文本计算，看每种颜色在 wikidot 骨架上画的是哪部分。改动下面的 CSS 或粘贴你自己的：运行的就是扩展里的代码。

只读文本，看不到图片，用图片画出的颜色不算在内。

原理

wikidot 站点几乎都用同一套 HTML 骨架，版式都写在同一个元素里。所以可以只换版式，不动页面的其他部分。

  1. 找到元素

    内容脚本在 document_start 运行，等待 <style id="internal-style">。没有它的页面不做任何改动。

  2. 保留基础样式

    保留 common--modules/ 和 common--theme/base/，去掉其余 @import，也就是管理员设置的版式。

  3. 插入所选版式

    紧跟着插入 <style id="pretty-enough-theme">。页面里的 [[module CSS]] 仍排在版式之后，层叠顺序不变。

使用前可以了解

为什么申请所有网站的访问权限

wikidot 站点可以使用任意域名，版式也可能托管在任何地方。内容脚本因此在每个网页上运行，但只检查页面有没有 #internal-style，不是 wikidot 页面时不读取设置，也不做任何改动。

有哪些已知限制
  • 有些站点在 nav:top、nav:side 里放了只给原版式准备、平时被它隐藏的内容，换版式后会露出来。除顶栏外不做处理。
  • 页面里的 [[module CSS]] 保留不动，可能与新版式冲突。
  • 设置在确认页面是 wikidot 站点之后才读取，原版式可能在首次绘制前短暂出现。
